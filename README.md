#### Other "Generally Useful" Resources
* [List Of Android ROMs/GSI ROMs/Recovery Images](https://github.com/musabcel/android_rom_list) (Not only for the Ulefone Armor 30 Pro)
* [The Original Shizuku](https://github.com/RikkaApps/Shizuku) (Enables root-like capability with certain apps.)
* [Recommended Shizuku Fork](https://github.com/thedjchi/Shizuku) (A better version, with the ability to start up without a PC!)
* [Universal Android Debloater Next Generation](https://github.com/Universal-Debloater-Alliance/universal-android-debloater-next-generation) (Use with a PC.)
* [Canta Debloater](https://github.com/samolego/Canta) (Use with Shizuku.)
* [Hail](https://github.com/aistra0528/Hail/blob/master/README_EN.md) (Freeze/Disable/Suspend/Uninstall* System Apps without root. *Uninstalling completely with files requires root.)
* [ShizuWall](https://github.com/AhmetCanArslan/ShizuWall) (A system-level firewall without root, powered by Shizuku.)
* [App Ops](https://appops.rikka.app/) (Permission Manager, powered by Shizuku.)
* [JamesDSP Rootless](https://github.com/timschneeb/RootlessJamesDSP) (ViPER Audio alternative without root. This allows for very nice audio quality, even on cheaper headphones/earbuds/speakers/etc.)
* [Magisk Root](https://github.com/topjohnwu/Magisk) (Systemless Root)
* [F-Droid](https://f-droid.org/en/) (Open Source App Store - Many great apps are found here, including some in this list!)
* [Brave Browser](https://github.com/brave/brave-browser/wiki/Installing-Brave-on-Android) (The best open source browser with powerful adblocking! - This link takes you to the page with the F-Droid Custom Repos.)
* [Aurora Store](https://auroraoss.com/aurora-store) (Access the Google Play Store without Google Play Services!)



##### Advanced Resources (Very niche tools for advanced users only!)
* [Dhizuku](https://github.com/iamr0s/Dhizuku) (A tool for sharing DeviceOwner permissions with other applications. Not related to Shizuku, despite having a very similar name.)
* [OwnDroid](https://github.com/BinTianqi/OwnDroid) (Use Android Device owner privilege to manage your device. Goes with Dhizuku.)
